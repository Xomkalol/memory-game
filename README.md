# Memory Game — Pokémon

Memory Game — учебный проект, в котором игрок должен найти все пары одинаковых карточек с покемонами.

Игра представляет собой поле 4×4 с 16 карточками. На поле находятся 8 разных покемонов, каждый из которых представлен двумя карточками.

## Возможности

- случайное перемешивание карточек при начале новой игры;
- открытие двух карточек за один ход;
- проверка совпадения найденной пары;
- блокировка поля во время ожидания закрытия несовпавшей пары;
- подсчёт количества ходов;
- подсчёт найденных пар;
- модальное окно после завершения игры;
- возможность начать новую игру без перезагрузки страницы;
- таблица лидеров с 10 лучшими результатами;
- сохранение результатов в `localStorage`;
- сохранение результатов между перезагрузками страницы.

## Технологии
